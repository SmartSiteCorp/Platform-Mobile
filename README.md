# Platform-Mobile

Native mobile apps for **SmartSite** (gestion de chantiers).

| Folder | Platform | Status |
| ------ | -------- | ------ |
| [`Android/`](Android/) | Android (Kotlin, Jetpack Compose) | Alpha v0.1.0 — verified on emulator |
| [`iOS/`](iOS/) | iOS (SwiftUI) | Alpha — code complete, **pending first Xcode build on a Mac** |

Both alphas share the same scope: 9 screens, in-memory mock data (no backend,
no network), French UI. See [`Android/README.md`](Android/README.md) and
[`iOS/README.md`](iOS/README.md) for build and run instructions.
